\chapter*{Code Availability}
\addcontentsline{toc}{chapter}{Code Availability}

The complete source code for all experiments, system architectures, and evaluation scripts presented in this thesis is publicly available on GitHub:

\begin{center}
\url{https://github.com/NourJadiri/hybrid-text-classification}
\end{center}

The repository includes:
\begin{itemize}
    \item Implementation of all three system architectures (baseline, AutoGen multi-agent, and actor-critique pipeline)
    \item Data preprocessing and evaluation scripts
    \item Configuration files and hyperparameters
    \item Instructions for reproducing the experiments
\end{itemize}
